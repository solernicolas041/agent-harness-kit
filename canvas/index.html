Three fill-in canvases · two derived from Addy Osmani's essays

Harness, Loop & Job Sheet

Three blank canvases: what the agent is, what makes it run, and what it may touch on one real account. Write straight into the boxes, or print them and use a pen. No code, no account.

1. Click any box and type. 2. Your text saves in this browser. 3. A box you can't fill is a gap in your design, not a formatting problem. 4. Leave the guardrail boxes empty on day one — you haven't made the mistakes yet.

Canvas 01

The Harness

Everything around the AI: what it reads, what it may touch, what it may never do. The model is the engine. This is the car.

1Prompting

What does it read every single time?

rules file · under 60 lines · 3 rules earned from a real failure

2Tools

What is it allowed to touch?

list them · keep under ten · one you removed because it confused it

3Infrastructure

Where does it work?

folder · can it undo its own damage · what it must never reach

4Knowledge

What does it know without being told?

file where project facts live · who adds to it, when

5Context

What happens when it fills up?

what gets summarised first · where big outputs get parked · the one file that must survive a full reset

6Loop

When does it run, and when is it done?

trigger · "done" means · give-up condition — then fill Canvas 02

7Guardrails — what it can never do

Write the thing that would actually hurt if it happened. Everything here becomes a wall.

blocked action → what happens instead · the automatic check that must pass before it may say "done" · success is silent, failure is loud

↻The Ratchet — mistakes turned into rules

This box is the whole method. A harness gets good by collecting scars, not by being designed well on day one. “The ratchet” is Osmani's term.

date · what went wrong · the rule it became · where that rule now lives

Canvas 02

The Loop

What makes the harness run without you typing anything. Boxes are numbered in the order one lap runs.

1Trigger

What starts it, without me?

runs every · the instruction, word for word · longest it may run

2State

Where does it remember, between runs?

memory file · what it records · what it must never record

3Isolation

How do two runs avoid each other?

each run gets its own copy of · what they would collide over · cleanup

4Skills

What am I tired of re-explaining?

knowledge file → the explanation it replaces · the thing it keeps getting wrong

5Maker & Checker

Two agents. An AI asked to grade its own work will pass itself, every time.

maker: who, and its instructions · checker: a DIFFERENT agent, fresh, told to prove the maker wrong · what happens if they disagree twice

6Connectors

Where does it touch the real world?

connector → the action it can take → reversible yes/no · anything "no" needs a human first

7Human gate — the part that never automates

“A loop running unattended is also a loop making mistakes unattended.” — Addy Osmani

where finished work lands for me · actions that are NEVER automatic · how I find out the loop died quietly

↻One lap, on paper, before you build anything

Walk it through in writing. Then answer the last question honestly — you already know the answer.

trigger fires → reads state → scans → isolates → maker → checker → acts → my inbox → writes state · where does this break first? · cost of one lap

↻ then it writes what it learned, and waits for the next trigger the loop proposes · you decide

Canvas 03

The Job Sheet

One sheet per account the agent works on. Canvas 01 says what the agent is. This says what it is allowed to touch on this client, with this money.

1Scope

Exactly which accounts, and what is the one thing being defended?

account IDs, in full · core objective in one line · what is NOT in this sheet

2Read rights

What may it look at without asking anyone?

the pull it must always run first · spend windows · what reading costs money or rate limit

3Write rights — every one of them gated

A read right is a habit. A write right is a decision. Name the gate for each.

action → who approves → hard ceiling per operation · outbound messages: draft only? · a ceiling is not an approval, you need both

4Thresholds

The numbers a decision is allowed to lean on.

currency · target cost per result · target return · monthly ceiling · alert rule

5Triggers

What wakes it up on this account, and what does it load first?

event → the sheet, rules and registers to read before acting · the check for "someone already handled this"

6Guardrails — and the scars they came from

A line only lands here after something went wrong. Do not pre-fill this from imagination — you will invent the wrong walls and miss the real one.

absolute prohibitions, each with the incident behind it · date · what it cost · settled subjects nobody may reopen

?The blanks you could not fill

This box is why the sheet works. A number you do not have is written down as missing, never guessed. An invented threshold is more dangerous than an absent one: the agent will act on it.

to confirm — need X · who can answer · what is being decided blind until they do

? a blank is a finding, not a formatting problem read rights are given · write rights are granted, one at a time
